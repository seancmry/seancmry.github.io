# seancmry.github.io

## The problem

A GitHub profile alone is easy to miss. People also want a simple public page: who you are, what you work on, how to reach you.

**What this repo does:** it is the source for the personal site at <https://seancmry.github.io> — static HTML/CSS served by GitHub Pages.

## Who it helps

- Visitors who landed from LinkedIn, a talk, or a repo  
- Anyone who wants contact links without digging through GitHub settings  

## How to run

**View live:** open <https://seancmry.github.io>.

**View locally:**

```bash
git clone https://github.com/seancmry/seancmry.github.io.git
cd seancmry.github.io
open index.html
```

No build step. Edit `index.html` / `style.css`, commit, and push to `main` to publish.
